# Курсовая работа

## Содержание: 
1. Функция чтения excel-файла
2. Функция получения трат по заданной категории за три месяца
3. Функция поиска транзакций по слову
4. Функция определения курса валют
5. Функция, определяющая общую сумму расходов
6. Функция группировки по категориям
7. Функция, определяющая общую сумму поступлений
8. Функция сортировки поступлений по категориям
9. Функция сортировки операций в диапазоне дат
10. Декоратор записи результата функции в файл

## Установка:
1. Клонируйте репозиторий:
(`git clone`) [GitHub] (https://github.com/zelenyzar/Project2026)
2. Установите зависимости
(`pip requirements.txt`)

## Использование проекта:
1. Откройте проект;
2. Введите данные запрашиваемые программой.
